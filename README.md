# TurboFlix

Player IPTV pessoal em formato PWA, desenvolvido para uso em celular e Fire TV.

## Recursos

- Importação de playlist M3U por URL.
- Login com servidor Xtream Codes.
- TV ao vivo.
- Filmes.
- Séries.
- Busca por nome.
- Favoritos.
- Histórico de reprodução.
- Função “Continuar assistindo”.
- Player para streams compatíveis.
- Tema escuro com detalhes roxos.
- Interface adaptada para celular.
- Navegação com teclado e controle remoto.
- Instalação como aplicativo PWA.
